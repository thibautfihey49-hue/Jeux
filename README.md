# 🌍 Monde Ouvert — Jeu Android

Jeu 3D monde ouvert pour Android, buildable depuis GitHub Actions.

## 🚀 Build APK automatique
- Va dans l'onglet **Actions** → **Build APK Android** → **Run workflow**
- Télécharge l'APK dans **Artifacts** en bas

## 🎮 Contrôles
- 🕹️ Joystick tactile : déplacer le joueur
- ⌨️ ZQSD : se déplacer
- ␣ Espace : sauter

✅ **Sans AndroidX** | Min SDK 24 | Godot 4.3
